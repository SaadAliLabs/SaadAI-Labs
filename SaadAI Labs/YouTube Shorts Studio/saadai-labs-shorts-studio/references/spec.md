# File formats

## Folder layout
```
<channel folder>/                 e.g. ~/Shorts/brain-snacks/
  channel.json                    channel memory: niche, look, voice, characters (example: examples/channel.json)
  history.md                      one line per published short (date | topic | format | hook) - avoid repeats
  ideas.md                        idea backlog from Idea mode
  shorts/<yyyy-mm-dd-slug>/
    short.json                    the script + scenes (you write this)
    props.draft.json / props.json generated by build.py
    storyboard.jpg  qa.jpg        generated previews
    voice/                        generated narration (cached per scene)
    <slug>.mp4                    the final short
    upload.md                     title, description, hashtags, pinned comment
```

## channel.json
| key | meaning |
|---|---|
| `name`, `niche`, `audience`, `language` | who it's for (language `en` for now; captions/whisper are English-tuned) |
| `formats` | formats this channel rotates through (explainer, story, myth-vs-fact, ranking) |
| `theme` | colours: `bg1` `bg2` (background gradient), `ink` (text), `muted`, `accent` (highlight 1), `accent2` (highlight 2), `card`, `cardInk` |
| `voice` | `provider`: `auto` (ElevenLabs if a key is set, else Kokoro) / `kokoro` / `elevenlabs` / `say`; `gender`: `male` (default) or `female`; `name`: Kokoro voice or blend (blank = default male blend); `speed` (Kokoro 1.05-1.2, default 1.12); `id`: ElevenLabs voice id (blank = Brian); `model`, `stability` |
| `music` | `upbeat` / `calm` / `mystery` / `hype` / `none` (or a custom `<name>` wav in the engine's public/music) |
| `musicVolume` | 0.05-0.12 (default 0.08). The voice must always dominate. |
| `captionStyle` | `pop` (active word turns accent colour) or `box` (active word in an accent box) |
| `watermark` | small @handle at the top, optional |
| `characters` | the recurring cast: `{id: {skin, hair, hairColor, shirt, pants, shoes, glasses, beard}}`; hair: `short` `long` `bun` `curly` `bald` `cap` `spiky` |
| `cta`, `never` | pinned-comment call to action; topics to never make |

If the user gives an **image** (a character drawing, a logo, a brand screenshot), look at it and translate it:
dominant colours → `theme`; a character's skin/hair/clothes → a `characters` entry. Tell them what you mapped.

## short.json
```json
{"topic": "...", "format": "explainer|story|myth-vs-fact|ranking",
 "hook_options": ["...", "...", "..."], "music": "upbeat", "scenes": [ ... ]}
```
Optional top-level overrides: `theme`, `characters`, `voice`, `musicVolume`, `captions` (false to hide), `captionStyle`, `watermark`.

Every scene has `type` and `say` (narration for that scene; `*asterisks*` are stripped before voicing).
Optional on any scene: `hold` (minimum seconds), `notes` (ignored; for your reasoning).

### Explainer scene types
| type | fields | use for |
|---|---|---|
| `hook` | `title` (≤ 6 words, *accent*), `emoji`, `sub` | scene 1 |
| `text` | `text` (≤ 12 words), `emoji` | a statement on a white card |
| `icon` | `emoji` (giant), `label`, `orbit` (up to 6 small emojis circling) | a concept, an object, a character-less "thing" |
| `stat` | `value` (number), `prefix`, `suffix` (`%` fills the ring to that %), `decimals`, `label`, `emoji` | any number |
| `list` | `title`, `items: [{emoji, text, cue}]` (2-5 items) | steps, reasons, examples; each item pops in when the narration says its `cue` word |
| `compare` | `title`, `left` / `right`: `{emoji, label, sub, cue}`, `winner` (`left`/`right`), `vs` | myth vs fact, before/after, A vs B; the right card arrives on its `cue` word |
| `end` | `text`, `emoji` | the loop line |

### Story scene type
```json
{"type": "story", "bg": "city", "title": "optional big line at the top", "camera": "zoom",
 "cast": [{"id": "max", "x": 0.3, "expr": "happy", "pose": "point", "speaking": true, "flip": false, "scale": 1, "enter": "pop"}],
 "props": [{"emoji": "💰", "x": 0.7, "y": 0.35, "size": 140, "anim": "fall", "cue": "paid"}],
 "bubble": {"who": "max", "text": "short line", "kind": "say|think|shout"},
 "say": "narration"}
```
- `bg`: `city` `room` `park` `office` `night` `space` `classroom` `kitchen`
- `camera`: `zoom` (slow push-in, default) `pan` `punch` (tight) `shake` (impact, plays a hit sound) `none`
- `cast[].expr`: `neutral` `happy` `sad` `shocked` `angry` `thinking` `smug`
- `cast[].pose`: `idle` `wave` `point` `cheer` `shrug` `think` `hips` `facepalm` `run`
- `cast[].x`: 0-1 across the frame (two characters: 0.3 and 0.72). `flip` makes them face left. `enter`: `pop` `left` `right` `none`.
- `speaking: true` makes the mouth move while narration words are being spoken.
- `props[].x/y`: 0-1 of the frame. Keep `y` between 0.15 and 0.6 (captions live at 0.65-0.78). `anim`: `float` `bounce` `spin` `pop` `shake` `fall`; `cue` makes it appear on that narration word.
- `bubble`: ≤ 9 words. Use it for dialogue the narration doesn't say word-for-word, or for the punchline.
- Story scenes can be mixed with explainer scenes in one short (e.g. story hook → `stat` → story → `end`).

## Safe zones (1080x1920)
- Top 0-200: YouTube's search/camera icons. Only the optional watermark lives at 120.
- 220-1220: all visuals. Story ground line is y=1200.
- 1255-1500: captions.
- 1500-1920 and the right 130 px: YouTube's title, channel name and buttons. Nothing important there.
The engine already respects these; don't fight it with custom positions.
